# Make the AI Judge Laugh

An entry for the [Make the AI Judge Laugh](https://make.fun/c/u-rama-melon-make-the-ai-judge-laugh-302d0825) bounty on make.fun.

`main.ts` (Node 22, standard library only, deterministic, offline) writes one
original one-line joke about office life to `/output/entry.txt`:

> My job description says 'other duties as assigned', which is how I became the printer's therapist.

The joke is built on a true office observation — the "other duties as
assigned" clause in every job description, and the office printer as the
eternal problem child — with the surprise landing in the last two words.
